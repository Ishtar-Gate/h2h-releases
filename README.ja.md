# Highway2Hell

[English](README.md) · [中文](README.zh-CN.md) · 日本語

Highway2Hell は、オンラインの動画や音声をダウンロードするデスクトップアプリです。無料のコマンドライン型ダウンローダー [yt-dlp](https://github.com/yt-dlp/yt-dlp) のグラフィカルインターフェースで、コマンドを打たずに使えます。

## ダウンロードとインストール

[Releases ページ](https://github.com/Ishtar-Gate/h2h-releases/releases)を開きます。いちばん上の「Latest」と付いているものが最新版です。その下の **Assets**（ダウンロードファイルの一覧）から、お使いのシステムに合ったファイルをダウンロードします。

| システム | ファイル |
|---|---|
| Windows | 名前が `_x64-setup.exe` で終わるもの |
| macOS（Apple シリコン、M1 以降）、未テスト | 名前が `_aarch64.dmg` で終わるもの |
| macOS（Intel）、未テスト | 名前が `_x64.dmg` で終わるもの |
| Linux、未テスト | 名前が `.AppImage` で終わるもの（`.deb` / `.rpm` も可） |

お使いの Mac のチップがわからないときは、画面左上の Apple メニューから「この Mac について」を開きます。「チップ」に Apple M1、M2 などとあれば Apple シリコン、「プロセッサ」に Intel とあれば Intel です。

Linux では、`.AppImage` はほとんどのディストリビューションでそのまま動きます。`.deb` は Ubuntu や Debian 用、`.rpm` は Fedora など用です。迷ったら `.AppImage` を選んでください。

macOS 版と Linux 版はまだテストしていません。問題があれば、下の「問題の報告」の方法でお知らせください。

ダウンロードしたファイルを開き、インストーラーの指示に従ってください。yt-dlp を自分でインストールする必要はありません。初回起動時に、必要なプログラムをアプリがダウンロードします。macOS と Linux の ffmpeg だけはご自身でインストールしてください。下の[ダウンロード用ツールを自動でインストールできないとき](#ダウンロード用ツールを自動でインストールできないとき)をご覧ください。

新しいバージョンが出るとアプリがお知らせし、確認するとアップデートをインストールします。

## ダウンロード用ツールを自動でインストールできないとき

Highway2Hell はダウンロードにいくつかの別のプログラムを使います。アプリではまとめて「ダウンロード用ツール」と呼んでいます。

- **yt-dlp**：動画の情報を読み取り、ダウンロードします。
- **ffmpeg**：映像と音声を 1 つのファイルにまとめたり、形式を変換したりします。
- **deno**：一部の YouTube 動画をダウンロードするときに yt-dlp が使います。

ふつうはアプリがこれらを自動でダウンロードしてインストールします。自動でインストールできないときは、どのプログラムをご自身でインストールすればよいかをアプリがお知らせします。

- macOS と Linux では、ffmpeg をご自身でインストールします。
- 一部の種類のパソコンでは、yt-dlp や deno もご自身でインストールが必要なことがあります。

各プログラムの公式の説明に沿ってインストールしてください。

- ffmpeg：[公式ダウンロードページ](https://ffmpeg.org/download.html)
- yt-dlp：[公式インストールガイド](https://github.com/yt-dlp/yt-dlp/wiki/Installation)
- deno：[公式インストールガイド](https://docs.deno.com/runtime/getting_started/installation/)

公式の説明にはいくつかのインストール方法があります。ソフトウェアのインストールツールを使ってください。macOS では Homebrew（Mac でよく使われる無料のインストールツール）、Linux ではシステムのパッケージマネージャー（たとえば Ubuntu の apt）です。この方法でインストールすれば、アプリがプログラムを見つけられます。プログラムのファイルをダウンロードしてどこかのフォルダーに置いただけでは、アプリは見つけられません。

インストールが終わったらアプリに戻ります。

- ffmpeg、yt-dlp：インストールを求められたページで「再検出」を押してください。
- deno：「このアプリについて」ページで「再検出」を押してください。

## 対応サイト

yt-dlp が対応しているサイトからダウンロードできます。一覧は yt-dlp の[対応サイト一覧](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md)をご覧ください。

## 問題の報告

[こちら](https://github.com/Ishtar-Gate/h2h-releases/issues/new/choose)から新しい issue（GitHub 上の問題報告）を作成してください。GitHub アカウントが必要です。

まず内容に合ったフォームを選んでください：Bug report（不具合の報告）、Feature request（機能の要望）、Translation（翻訳）、Other（その他）。フォームは英語ですが、日本語で書いてもかまいません。

可能であれば診断情報を添付してください。アプリのサイドバー下部の「このアプリについて」を開き、「診断情報をエクスポート」をクリックし、表示されるウィンドウで保存先を選ぶと `.zip` ファイルが保存されます。それを issue の入力欄にドラッグしてください。診断情報に Cookie は含まれず、プロキシのパスワードなどの機密情報は伏せ字になっています。隣の「問題を報告する」ボタンを押すと、Bug report のフォームが直接開きます。
